Messy founder updates in.
A checked, review-ready workbook out.

Every quarter a VC associate collects PDFs, decks, emails and CSV exports from each portfolio company and rebuilds the same monitoring workbook by hand. These agents do it end to end, then prove the result is right before anyone opens the file. Everything below is from one live run, unedited.

How it works

Five agents, each with one job and a written house standard. Narrow jobs keep behaviour predictable, and every rule in a standard is something a test can check.

Claude · xlsx skillGenerator

Reads all raw files in a code sandbox, normalises units, FX and definitions, builds the formula-driven workbook.

Claude · xlsx skillChart agent

Adds six native Excel charts to the Dashboard per the chart spec: no overlaps, legends below, outliers capped.

Claude + JEVValidator

Claude writes Correct/Incorrect question templates; JEV (System One) answers them cell by cell.

Claude visionChart reviewer

Looks at the rendered dashboard the way a partner would: label collisions, squashed outliers, colours.

Claude · xlsx skillUpdate agent

Merges a late report into the reviewed workbook without touching anyone else's data or review ticks.

Inputs: what the founders actually sent

Generated from one ground-truth file, so every number has a known right answer, and seeded with the traps associates really hit: contracted ARR in a footnote, burn that is never stated, EUR figures, a restated month, duplicated rows, and an email that tries to instruct the AI.
